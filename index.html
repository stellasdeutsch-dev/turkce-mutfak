01 · Слово + слово

Ледяной шкаф

Второе слово получает окончание -ı / -i / -u / -ü (после гласной — -sı / -si / -su / -sü). Глухая на конце может смягчиться: p → b, k → ğ.

buz+dolap
p → b, + ı
02 · Суффикс -lık

Штука для…

-lık превращает «что» в «штуку для этого». Гласная внутри суффикса подстраивается под последнюю гласную слова: a, ı → ı · e, i → i · o, u → u · ö, ü → ü.

tuz lık
03 · Где лежит?

— где?

«В / на» — это не предлог, а хвост: -da / -de. После глухих согласных — -ta / -te. Глухие легко запомнить фразой Fıstıkçı Şahap — «фисташковый Шахап»:
