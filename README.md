# Турецкий на кухне — Alterna

Лексический гайд «На кухне» (A1): 3D-кухня с озвучкой, истории в формате тредов, три конструктора слов,
12 фраз, тест. В конце — продающий блок платформы **Alterna Timur A0 → C1**.

Живой сайт: https://stellasdeutsch-dev.github.io/turkce-mutfak/

Дизайн по мотивам N2W (Behance): кремовый фон, жёлтый `#FFE083`, персиковый, синий, чёрные кнопки-«таблетки»,
плотный гротеск Inter Tight в заголовках, зернистые 3D-звёзды и аниме-небо. Mobile first.

## Интерактив

1. **3D-кухня** — тап по предмету: слово, транскрипция, пример, озвучка (обычная и медленная).
   Горизонтальный свайп крутит кухню, вертикальный листает страницу.
2. **Найди на кухне** — 10 раундов: слышишь слово, ищешь предмет.
3. **Слово + слово** — buz + dolap → buzdolabı, с подсветкой смягчения.
4. **Суффикс -lık** — «слот-машина» гармонии гласных: tuz → tuzluk.
5. **Nerede?** — местный падеж -da/-de/-ta/-te с подсветкой Fıstıkçı Şahap.
6. **Тест** из 8 вопросов с конфетти.
7. **Платформа**: живой прогресс «ты прослушал N из 26», реальный скриншот темы «На кухне» из Notion,
   выбор сценария, видео разделов, экраны телефона, калькулятор времени на поиск, автор, оффер.

## Визуал и анимации (v2)

- **3D-иконки**: каждый предмет кухни рендерится отдельно (three.js, offscreen) — они в сетке слов, карточке слова и тесте
- **3D-чайник в hero** + «магнитики» со словами (парят, реагируют на курсор, говорят по тапу)
- **Чайный ритуал** — сцена, которая проигрывается от скролла: кипение → заварка → таймер 15 минут → наливаем «tavşan kanı»; плюс açık / tavşan kanı / koyu
- **Бегущие строки** слов и фраз — ускоряются от скорости скролла, каждое слово озвучено
- Заголовки выезжают по словам, всплывашка «сейчас звучит», рябь по нажатию, «магнитные» кнопки, coverflow телефонов, выскакивающий дашборд

## Озвучка

Голос синтезированный — системный `Yelda` (tr_TR) из macOS, не запись живого человека.
Пересобрать: `python3 tools/gen-audio.py` (нужны macOS, ffmpeg, node).
Чтобы заменить на живой голос, положи mp3 с тем же именем в `audio/`.
Если файла нет, сайт озвучит слово синтезом речи браузера.
